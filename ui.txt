For a telecom/business analytics application, I would use a technical enterprise dashboard rather than the usual AI-dashboard aesthetic.

Font: IBM Plex Sans

I recommend IBM Plex Sans.

It has a more technical/product-analytics feel than Inter, Poppins, Montserrat, etc.

Use:

font-family: "IBM Plex Sans", sans-serif;

For headings, don't use an extremely heavy weight. Use:

Page title: 600
Section headings: 600
Body: 400
Labels: 400–500

Your current title is too heavy:

Customer Churn Prediction Dashboard

Make it slightly smaller and lighter.

Color palette

I would move away from the current red/blue Streamlit palette.

8. SHAP section

This is where I would make the biggest visual change.

Your screenshot currently has:

Contract_One year

with bright red bars.

Teal would look much more deliberate.

Important

Don't use red for SHAP just because churn is the target.

SHAP bar importance represents magnitude of contribution, not necessarily "bad" or "good".

So red is actually semantically misleading here.

9. SHAP beeswarm

Keep the standard SHAP color scheme here.

The beeswarm's red/blue feature-value encoding has semantic meaning:

red → high feature value
blue → low feature value

So don't recolor the beeswarm arbitrarily.

Your global importance bar chart can be teal; the beeswarm should retain its conventional interpretation.

One more change: don't use Inter

I would specifically avoid:

Inter
Poppins
Montserrat
Roboto

They aren't bad fonts, but they're heavily represented in modern AI-generated dashboards.

IBM Plex Sans is a better choice for this particular project.

Final visual identity

I'd aim for:

IBM Plex Sans + Slate/Navy + Teal + restrained semantic red/green

rather than:

Inter + dark background + Streamlit red + blue + rounded cards.
